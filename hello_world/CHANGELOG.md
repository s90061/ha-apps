# Changelog

## 0.1.0

- Initial release of the Hello World starter app (`amd64` and `aarch64`).
- Configured Home Assistant Alpine base (`3.23`) with `s6-overlay` v3 (`user-bundles.d`) and `bashio`.
- Added English and Traditional Chinese UI translations, configurable `message` and `interval_seconds`, and LF/permission hardening.
