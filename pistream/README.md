# Home Assistant App: PiStream

_Lightweight Raspberry Pi 5 media server (`s90061/pistream`, `aarch64`) featuring HTTP 206 Direct Play, zero-copy Remux (`-c:v copy`), sliding-window HLS transcoding, and multi-user watch progress._

![Supports aarch64 Architecture][aarch64-shield]

See [DOCS.md](./DOCS.md) for Ingress & direct port `8080` streaming, `/media` & `/share` integration (including `aMule`), and configuration options.
